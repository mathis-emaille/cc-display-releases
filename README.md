# CC Display Companion - téléchargements

Installeurs de **CC Display Companion**, l'app Windows qui affiche l'usage Claude / OpenAI dans un widget toujours visible et sur le boîtier CC Display.

## Installer

1. Téléchargez `CCDisplayCompanion-Setup-<version>.exe` depuis la [dernière release](../../releases/latest).
2. Lancez-le (pas besoin des droits administrateur). Windows peut afficher « Windows a protégé votre ordinateur » : cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.
3. Dans l'app, cliquez sur **+ Ajouter un compte** pour connecter vos comptes.

## Mises à jour

L'app vérifie elle-même les nouvelles versions publiées ici et propose de les installer : rien à retélécharger à la main.

Chaque installeur est accompagné d'un fichier `.sha256` que l'app utilise pour vérifier le téléchargement.
